# Unity + LLM NPC Demo

用自然语言驱动 Unity 场景里的 NPC：LLM 把玩家的话解析成结构化指令（`spawn` / `move` / `look_at`），NPC 在预设的语义锚点上行动。

- 定位：求职作品，对着「Unity + LLM 驱动的 NPC 交互」这条考纲做
- 当前状态：规格定稿中（见 [PROGRESS.md](PROGRESS.md)）
- 规格文档：[docs/SPEC.md](docs/SPEC.md)
