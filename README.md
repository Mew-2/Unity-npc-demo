# Unity + LLM NPC Demo

用自然语言驱动 Unity 场景里的 NPC：LLM 把玩家的话解析成结构化指令（`spawn` / `move` / `look_at`），NPC 在预设的**语义锚点**上行动。

这份 demo 不证明"Unity 年限"——目标 JD 的任职要求里没有引擎锁定，引擎只出现在加分项。它要证明的是三件事：

1. **引擎基本原理**能落成看得见的结果：渲染（URP 实时光 + Bloom）、动画（Animator 状态机 + 转身插值）、物理（CharacterController 碰撞）。
2. **LLM 能安全地驱动真实管线**：结构化输出 + 结构校验 + 失败重试，不是把模型输出直接丢给场景。
3. **内容生产场景的原型**：实体生成 + 语义布点（JD 原话）+ 锚点图。
