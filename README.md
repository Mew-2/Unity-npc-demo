# Unity + LLM NPC Demo

用自然语言驱动 Unity 场景里的 NPC：LLM 把玩家的话解析成结构化指令（`spawn` / `move` / `look_at` / `set`），NPC 在预设的**语义锚点**上行动。

场景：深夜卧室，两幕（侍寝 → 唤醒）。女仆会魔法，但关灯 / 窗帘 / 更衣走显式的 `set` 状态指令，不靠"魔法"兜底。

这份 demo 不证明"Unity 年限"——目标 JD 的任职要求里没有引擎锁定，引擎只出现在加分项。主叙事是**运行时**：玩家用自然语言指挥 NPC（Link Start 直系）；打磨阶段再加一段 30 秒"策划视角"（用 `spawn` + 语义布点演一句话布点），两种讲法共用同一套实现。它要证明的是三件事：

1. **引擎基本原理**能落成看得见的结果：渲染（URP 实时光 + Bloom）、动画（Animator 状态机 + 转身插值）、物理（CharacterController 碰撞）。
2. **LLM 能安全地驱动真实管线**：结构化输出 + 结构校验 + 失败重试，不是把模型输出直接丢给场景。
3. **内容生产入口的演示**：实体生成 + 语义布点（JD 原话）——同一套 `spawn`，换个讲法就是"策划一句话布点"。
